This repository contains  
1. Inaugural project. Answers to the set of questions *Project 0: Inaugural Project*. The project solves the economic problem of an exchange economy.
2. Data project. An analysis of the population projection in Denmark from 2023 to 2050. The analysis provides insights into changes in population distribution across age groups over time, facilitating a comprehensive understanding of demographic shifts. 
3. Model project. We model the standard Solow model and two extensions to this model: The Solow model with endogenous technological progress, and the Solow model with human capital. For all three models, we find the analytical solution, the numerical solution (for some baseline parameter values), and analyze the dynamics of the different models.
