# Data analysis project

Our project is titled **DataProject: Population Projection in Denmark**. It is an analysis of the population projection in Denmark from 2023 to 2050. The analysis highlights changes in population distribution across age groups over time, facilitating a comprehensive understanding of demographic shifts.

The **results** of the project can be seen from running [dataproject.ipynb](dataproject.ipynb).

We apply the dataset **FRKM123**. We fetch the data by using the Api from Statistics Denmark, DstApi.

**Dependencies:** Apart from a standard Anaconda Python 3 installation, the project requires the following installations:

``%pip install git+https://github.com/alemartinello/dstapi``

This is also automatically installed when running the [dataproject.ipynb](dataproject.ipynb) file.
