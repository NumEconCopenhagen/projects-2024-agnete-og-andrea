# Data analysis project

Our project is titled **DataProject: Population Projection in Denmark** and is about the development of the Danish population from 2023 to 2050.

The **results** of the project can be seen from running [dataproject.ipynb](dataproject.ipynb).

We download the data from DST via the DST API wrapper.

**Dependencies:** Apart from a standard Anaconda Python 3 installation, the project requires the following installations:

``%pip install git+https://github.com/alemartinello/dstapi``

This is also automatically installed when running the [dataproject.ipynb](dataproject.ipynb) file.
