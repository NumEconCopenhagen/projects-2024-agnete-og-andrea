# Model analysis project

Our project is titled **The Solow Growth Model**. The project provides a comprehensive exploration of the Solow growth model and some of its extensions. We look into the standard Solow growth model, the Solow model with semi-endogenous technology progress, and the Solow model with human capital.

The **results** of the project can be seen from running [Solow.ipynb](Solow.ipynb).

**Dependencies:** Apart from a standard Anaconda Python 3 installation, the project requires no further packages.
